# Source Model Viewer

![Source Model Viewer screenshot](image.png)

A Python 3D viewer for Source engine models.

## Features

* **Models** | Supports MDL, SMD, DMX model formats and VTA for vertex animation.
* **Textures** | VTF support for applying textures onto models.
* **Controls** | Controls for animation sequences and flex shapes.
* **Settings** | Configure materials, viewport and more.

## Packages

* **numpy** | For model optimization.
* **PySide6** | For the program interface.
* **PyOpenGL** | For 3D rendering.
